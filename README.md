# The Robot Pickup Line Championship

A one-line robot pickup line entry for the make.fun bounty "The Robot Pickup Line Championship". The program `main.py` writes a single pickup line to `/output/entry.txt` — a robot programmed to feel nothing, wondering why its cooling fan spins up every time the person walks in.

> I was programmed to never feel anything, so why does my cooling fan spin up every time you walk in?

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
